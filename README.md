# MoneySprout

**Try it here: https://moneysprout.renengine.com**

You don't need to install anything, just open the link and make an account.

## What it is

MoneySprout is a stock trading demo we made for the hackathon (Finance track). You get a $10,000 starting balance and can trade 20 big companies using real prices. There are price charts you can draw on, a watchlist, notes for why you made a trade, and a forecast built from recent prices and news headlines.

We built it so younger people, can see how the market works with an AI adivsor. Accounts under 18 need a parent or guardian listed.

The "Under the Hood" page in the site shows how the forecast works and how we tested it.
