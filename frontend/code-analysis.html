1. How the prediction works

It all lives in backend/services/predict.py. When you hit Predict on a stock page, the server runs these steps in the background so the page can show you how it is going.

  1. Get the price history from Yahoo Finance.
  2. Work out the trend and how jumpy the price is, using the last 60 moves. The trend is capped so it cannot run away.
  3. Search the news. Seven searches run at the same time, the results get merged and the repeats get tossed, and the newest 45 headlines are kept. We hold on to them for 15 minutes.
  4. Score every headline from -1 (bad) to +1 (good) with the keyword list.
  5. Context rules fix the silly mistakes. Shows and movies get ignored, and executive scandals get pushed to negative.
  6. If the AI loaded, it re-reads the 16 most important headlines and says good, bad, neutral or not relevant.
  7. Squash it all into one mood number. Newer headlines count more, a small pile gets pulled toward zero, and serious stuff gets an extra push down.
  8. Draw the forecast line. The trend fades out, a price that ran too far gets pulled back toward its average, a little wiggle is added, and the shaded range gets wider the further out you look.
  9. If the AI loaded, it also gives its own outlook and percent change. That gets mixed 75/25 with the stats line and capped.

The adapter is a text writer, not a classifier. So the keyword list always does step 4, and the adapter helps out in steps 6 and 9. If the AI fails anywhere, the app switches to the plain version and tells you why. That part works well and is worth keeping.

The AI is a LoRA adapter. Think of it as a small pile of tweaks that sits on top of a normal model, so we did not have to retrain the whole thing.

The context rules

A scary word is not always bad news. A show called "The Affair" is not a scandal. So quoted titles get stripped out, movie and trailer headlines get ignored, and a personal scandal only counts if an executive or owner is in the headline.

def judge(title, score):
    """(score, relevant, note) after the context rules."""
    words = set(re.findall(r"[a-z\-]+", strip_titles(title).lower()))
    if words & ENTERTAINMENT and not (words & BUSINESS):
        return 0.0, False, "About a show, film or trailer, not the company's business"
    if personal_scandal(title):
        return min(score, -0.85), True, "Executive scandal"
    return score, True, ""
def personal_scandal(text):
    clean = strip_titles(text)
    return bool(ROLES.search(clean) and PERSONAL.search(clean))

Squashing headlines into one number

def combine(items, scores, now=None):
    # newer headlines count more (about a 4 day half-ish life), and only a few
    # headlines means we are less sure, so the number is pulled toward 0
    now = now or time.time()
    wsum = 0.0
    ssum = 0.0
    severe_w = 0.0
    for it, s in zip(items, scores):
        age_days = max(0.0, (now - it["time"]) / 86400.0)
        w = math.exp(-age_days / 4.0)
        wsum += w
        ssum += w * s
        # an executive scandal / lawsuit / investigation is not cancelled out by ten
        # "stock rises" headlines, so negative ones like that get an extra push of their own
        if s < 0 and is_severe(it["title"]):
            severe_w += w
    if wsum <= 0:
        return 0.0
    base = (ssum / wsum) * (wsum / (wsum + 1.0))
    return max(-1.0, min(1.0, base - min(0.7, 0.3 * severe_w)))

Trend and swing

The forecast needs two numbers from the price history. The trend is the average move per step. The swing is how jumpy the price is. We cap the trend at 1.5 times the swing so it cannot run wild.

def _vol(points):
    # (trend per step, typical swing per step) from the recent prices, as log returns
    closes = [p["c"] for p in points]
    n = len(closes)
    if n < 8:
        return None
    look = min(60, n - 1)
    rets = [math.log(closes[i] / closes[i - 1]) for i in range(n - look, n) if closes[i - 1] > 0 and closes[i] > 0]
    if len(rets) < 5:
        return None
    mu = sum(rets) / len(rets)
    var = sum((r - mu) ** 2 for r in rets) / (len(rets) - 1)
    sigma = max(math.sqrt(var), 1e-5)
    # a trend alone should not be allowed to run away
    return max(-1.5 * sigma, min(1.5 * sigma, mu)), sigma

The AI double check

    cap = 2.5 * sigma * math.sqrt(steps)
    ai_end = max(-cap, min(cap, ai_end))
    target = 0.75 * ai_end + 0.25 * math.log(1 + stat_pct / 100)
    print("AI says", ai_pct, "-> capped", round((math.exp(ai_end) - 1) * 100, 1), "-> final", round((math.exp(target) - 1) * 100, 1))
AI says 6.0 -> capped 6.0 -> final 4.7
AI says 60.0 -> capped 31.5 -> final 23.1
AI says -60.0 -> capped -24.0 -> final -18.4

So if the AI says +60 percent on a stock that swings 2 percent a day, the app quietly shrinks that way down.

5. Test one: can it read a headline?

We wrote 63 headlines by hand in the style of real financial news: 20 good, 20 bad, 15 routine, and 8 that are not about the business at all. We labeled each one ourselves, then ran the keyword scorer and the context rules on them. No AI is involved here.

8. Test four: the forecast line and shaded range

For this one we made up stocks. Each has 250 days of random daily moves (about 2 percent a day). We ask the real forecast function for 30 days ahead, then make up what "actually" happens and check how it did. We used 1,500 stocks for each scenario.

Why fake prices? We did not have any real price history. The upside is that we know exactly how the fake world works, so we can tell if the code does what it claims. The downside is that it tells us nothing about real markets, and we are going to keep repeating that.

What this shows

  • When the fake world acts the way the code expects (steady jumpiness, independent days), the range does its job. 80.4 percent against 80 promised. That is the win.
  • Across all days it comes up a little short (76 percent), because the jumpiness is guessed from only 60 past moves.
  • When volatility suddenly jumps, the range only catches about 42 percent while still claiming 80. It only knows the past. Real shocks like earnings surprises and scandals are exactly when people lean on the range the most.
  • Direction was right about half the time everywhere, which is a coin flip. In our fake world the news has no link to prices, so there was nothing to find, and it found nothing. That is not a bug, but it also means this test could never have shown the forecast is any good.
  • When we gave it strong news that was pure noise, the average miss got about 28 percent worse than just saying "no change" (10.75 versus 8.40). That is the price of tilting the line on news that does not matter. In real life news sometimes does matter, and this test cannot tell us how often.

Here is how to read what comes out:

  • If the adapter row is not higher than the plain Qwen row, the adapter did not help on this test.

  • Check the line that counts good called bad, or bad called good. That is the worst kind of miss.

10. The math behind it

Not fancy proofs, just the arithmetic, so you can check our work.

Where 31.7 percent comes from: the biggest group in the headline set has 20 of 63 headlines, and 20 divided by 63 is 31.7 percent. Always guessing that group scores exactly that.

The 77 to 93 percent range is the Wilson 95 percent interval. It shows what the real accuracy could be.

# wilson interval, a range for what the real accuracy could be
def wilson(k, n, z=1.96):
    p = k / n
    d = 1 + z * z / n
    centre = (p + z * z / (2 * n)) / d
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return centre - half, centre + half

lo, hi = wilson(55, 63)
print("55 of 63 ->", round(lo * 100, 1), "to", round(hi * 100, 1))
55 of 63 -> 76.9 to 93.4

Why the range is 1.28 times sigma times the square root of k: if daily moves are independent with standard deviation sigma, the total move over k days has a standard deviation of sigma times the square root of k. A two-sided 80 percent range uses 1.28. So the formula is exactly right when moves are independent, bell-shaped and the jumpiness stays put. The simulation agrees when those things hold (80.4 percent) and falls apart when they do not (41.7 percent).

Why direction near 50 percent is nothing to worry about: with 1,500 trials a coin flip wobbles by about this much:

# with 1500 trials a coin flip wobbles about this much
print(round(math.sqrt(0.5 * 0.5 / 1500) * 100, 2), "percent")
1.29 percent

Our five results were 49.3, 51.6, 49.3, 50.6 and 49.4. All of them are within about 1.3 wobbles of 50, so they look like coin flips, which is what fake data should give.

11. What could go wrong

Things we saw in our tests

  • Words with two meanings fool the word lists ("fall" the season, for example).
  • A good word and a bad word in one headline cancel out, so real bad news can score neutral.
  • "better than expected" slips by because "better" is not on the list.
  • Non-business headlines only get ignored if they contain one of the listed entertainment words.
  • "fined" is not on the serious list, so a regulator fine does not get the extra push down.
  • If the AI's direction and number disagree, the code goes with the direction word.
  • The shaded range is way too narrow after a sudden jump in volatility.
  • Tilting the line on news that does not matter makes it worse than "no change".
  • Strong news takes the place of the trend instead of adding to it, so on a stock that is already rising fast, good news can lower the forecast a hair.

Things we spotted in the code but did not test

  • Daily forecasts skip weekends but not market holidays.
  • Repeats are caught using the first 70 letters of a title, so reworded copies count again.
  • Google results are kept if the title has the company name, so a name like Apple can pull in unrelated stories. Short tickers like F are skipped for that matching.
  • When the AI says good or bad, the strength is set to at least 0.5 in that direction, no matter what the earlier score was.
  • News is hours or days old by the time it is scored, and the price may have already reacted. The code has no way to know.
  • The three data feeds are unofficial and could change or block us at any time.

About the adapter

  • We have not measured accuracy yet. Test five is how to fix that.
  • One pass over about 10K lines at a fairly high learning rate (0.0002) is a light touch. It might have only learned the answer format and not much else, and we cannot tell until it is tested.
  • The FinGPT set only covers the 30 Dow companies for one year (May 2023 to May 2024). The app lets people pick any stock, so for most other companies the adapter may have seen much less.
  • The training prompts and the app prompts are probably different. The app asks for a verdict per headline and a JSON outlook. If the training data was written in another style, the adapter may help less than it should. We cannot check, because the training prompt format was not saved with the adapter.
  • Some of the training labels were written by a model, and those can be wrong or inconsistent. Our adapter learns those mistakes too.
  • The headline double check only looks at the top 16 headlines. The other 29 are scored by keywords alone.
  • The AI gets to see the stats line (the simple trend estimate) in its prompt, so its answer can lean toward it.

12. What these results do and do not tell us

This is the most important section, so we are going to be straight with you.

What they are fine for

  • Using the tool to help you read the news, so you can see which headlines look serious and read those first.
  • Using it as a demo that shows how news and price trends can turn into a rough picture.
  • Practicing with pretend money, which is what the app is for.

What they are not good for

  • Buying or selling real shares because of the forecast. We never compared it to real prices, so we have no proof it predicts anything in a real market.
  • Treating headline accuracy as price accuracy. 87 percent on 63 hand-picked headlines says it can roughly read a headline. It does not say prices move the way headlines suggest. Those are two different questions, and we only answered the first one.
  • Trusting the AI's percent change. We have not tested the adapter.
  • Using the shaded range as a safe limit or stop-loss. It only caught about 42 percent in the shock test while claiming 80. It fails right when a surprise hits.
  • Believing it beats just holding the stock. We never compared it to buy-and-hold, and we never counted trading costs or taxes.
  • Deciding how much to invest. A small sample and no real-price testing cannot answer that for anyone.

What we would need to trust it more

  • Run run5_adapter.py and put the real adapter numbers on this page.
  • A backtest on real past prices, with lots of stocks over several years, using only headlines that existed at the time.
  • Test on data the code never saw while we were building it, and compare against simple baselines: buy-and-hold, and the price trend alone with no news.
  • Count trading costs, and check that the results are bigger than luck.
  • Keep the test headlines out of the training data. Ours were hand-written, so they are safe, but a bigger test set from real feeds would need a check.

This is a class project, not financial advice. Nothing on this page is telling you to buy or sell anything.

13. Does it beat a simple baseline?

A baseline is the simplest guess you could make, like always picking the most common answer. If 87 out of 100 emails are not spam, a "model" that says "not spam" every time is already 87 percent right. So a score only means something when you put the baseline score right next to it. That is what analysis-tests/baseline.py does.

15. How we made this, and what to double check

  • Source code: backend/services/predict.py, news.py, market.py and routers/stocks.py from this project.
  • Tests: Python using the real functions from predict.py, run offline. The 63 headlines, their labels and the simulation settings are in the analysis-tests folder (headlines.py, run1 to run4). examples.py makes every code block on this page, baseline.py is the baseline comparison, and run5_adapter.py is the adapter test.
  • We wrote the headlines, their labels and the fake price worlds ourselves. None of it is real news or real prices.
